# OSMS - Online School Management System

A school ERP web application for managing students, faculty, attendance, marks, fees and syllabus, with separate dashboards for admin, faculty and students.

**Built with:** HTML, CSS, JavaScript, Node.js, Express and MongoDB (Mongoose)

## Features
- Home, About, Features and Contact pages (contact messages are saved)
- Role based login with Admin, Faculty and Student dashboards
- Student management and faculty management (add, view, edit, delete)
- Attendance management by class and division
- Marks entry and syllabus management
- Fees management with payment records and a receipt page

## How to run
1. Install Node.js and MongoDB (MongoDB must be running on `mongodb://127.0.0.1:27017`).
2. In this folder run `npm install`
3. Run `npm start`
4. Open http://localhost:3000

The database `schoolERP` is created automatically.
